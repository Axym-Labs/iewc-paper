\section{Inherited Label-Noise Stress Test}

We retain the rejected submission's CIFAR-100 label-noise experiment as exploratory evidence, not as part of the locked confirmatory comparison. Its endpoints were available during the earlier method-development workflow, so the table should not be read as an unbiased estimate after model selection. Uniform training-label flips create atypical high-loss samples, and the clean task-aware test set measures downstream retention. In this inherited experiment, IEWC loses less accuracy than observed-label OPG-EWC as the flip rate increases.
