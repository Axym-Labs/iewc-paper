# Previous TMLR build (archived)

`main.tex` and `main.pdf` are the former `tmlr/` build (the PDF was last
rebuilt at commit `619956f`, 2026-11-14). The TMLR version is now built from
the root `main.tex` with `make tmlr` (`tmlr.tex` sets the TMLR switch); the
official style files moved to the root (`tmlr.sty`, `tmlr.bst`,
`fancyhdr.sty`, `TMLR-STYLE-LICENSE`, `TMLR-STYLE-PROVENANCE.md`).
