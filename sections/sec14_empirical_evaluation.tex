\section{Empirical Evaluation}

We use two evidence tiers. The confirmatory comparison is frozen before locked-test access and asks whether IEF normalization helps relative to OPG under identical uniform weights and matched global diagonal scale. It uses disjoint train, validation, and locked-test roles; paired task orders and optimizer seeds; fixed five-point validation grids without edge expansion; and paired uncertainty on the held-out repetitions. The secondary $2\times2$ comparison crosses OPG/IEF with uniform/RDW aggregation. Sampled model-Fisher EWC and MAS are external regularization baselines; sequential training and offline/joint training provide lower-context and non-continual references. Appendix C specifies the complete protocol.

The rejected submission's experiments are retained below as an \emph{inherited exploratory record}. Their reported endpoints participated in hyperparameter and method development, so their numerical differences are not confirmatory and their across-seed dispersions do not repair that selection bias. Retaining them preserves the paper's empirical breadth and provenance without using them to decide the revised headline. Unless stated otherwise, all stored matrices are diagonal. The legacy names U-IEWC and GSS-IEWC denote uniform IEF and the earlier GSS-motivated weighting implementation, respectively; the latter is order dependent and is not evidence for normalization in isolation.

The selected legacy weighted run visually retains more target trajectory structure at the first task and stays close to the selected OPG-EWC run later; no uncertainty claim is made from these individual rollouts.

The earlier DDPM study also used a surrogate labeled ``sliced Wasserstein.'' Because it did not establish a matched primal/dual metric pair, we narrow its interpretation: the selected surrogate run had old-output drift $9.4409\pm7.2517$ versus $14.1026\pm12.2220$ for selected Euclidean U-IEWC, with denoising MSE $0.0301\pm0.0012$ versus $0.0298\pm0.0014$. This is retained as an exploratory output-representation ablation, not evidence validating Wasserstein geometry. Section~11 gives a correct ordered-CDF/Cram\'er construction.

The inherited FROMP-derived weighting ablation \citep{FROMP} was mixed: on ImageNet-R it reached $0.6365\pm0.0165$ final average accuracy and $0.3068\pm0.0170$ forgetting, while on VOC 15-5 it reached $0.3351\pm0.0742$ final all-mIoU and $0.4064\pm0.1122$ base-class forgetting. These selected endpoints likewise do not isolate normalization.

\subsection*{Code Release}

We release an accompanying repository with a readily usable IEWC implementation. The \texttt{IEWCConfig} class encapsulates the four-tuple parametrization introduced above. The same configuration interface is used by the diagonal and low-rank IEWC paths and by the empirical scripts, including the FACIL-based CIFAR-100 checks and the larger ImageNet-R, TRACE, forecasting, segmentation, and diffusion runs. The repository is available at \url{https://github.com/Axym-Labs/iewc}.
