\subsection{Normalization and Sample Weighting}
\label{sec:normalization-weighting}

To compare both matrices in a common notation, let $G_n\succ0$ denote the chosen output metric for sample $n$. Although $M_{\mathrm{OPG}}$ itself does not depend on $G_n$, its summands can be rewritten relative to that metric. In a negative-log-likelihood setting, $M_{\mathrm{OPG}}=F_{\mathrm{emp}}$.

Define
\[
\hat r_n^{\,G}
=
\frac{r_n}{\sqrt{r_n^\top G_n^{-1}r_n}},
\qquad
a_n^{\,G}
=
J_n^\top \hat r_n^{\,G},
\qquad
w_n^{\,G}
=
r_n^\top G_n^{-1}r_n.
\]
Then, wherever $r_n\ne0$,
\[
M_{\mathrm{IEF},G}
=
\frac{1}{N}\sum_{n=1}^N a_n^{\,G}(a_n^{\,G})^\top,
\qquad
M_{\mathrm{OPG}}
=
\frac{1}{N}\sum_{n=1}^N w_n^{\,G}\,a_n^{\,G}(a_n^{\,G})^\top.
\]

Both matrices empirically aggregate the same local old-task sensitivity directions $a_n^{\,G}(a_n^{\,G})^\top$, but they differ in how strongly each sample contributes. Undamped IEF keeps uniform empirical weighting of these normalized directions, while OPG multiplies each contribution by the metric-dependent squared magnitude
\[
w_n^{\,G}=r_n^\top G_n^{-1}r_n.
\]

Thus normalization changes sample aggregation: OPG shifts old-task weighting toward samples with large output-loss gradients and away from confidently fitted ones, whereas undamped IEF removes that scale.
