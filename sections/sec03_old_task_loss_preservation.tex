\section{Old-Task Loss Preservation}

Since $\ell_A$ is a practical surrogate for performance on distribution $A$, a natural choice is to use the loss itself to define preservation. We say that $f_\theta$ locally preserves an old sample if it preserves that sample's old loss value. This gives
\[
q(a,\theta)
=
\ell_A(f_\theta(x))-\ell_A(f_{\theta_A^\star}(x)).
\]
Since preservation means $q(a,\theta)=0$, take $\mathcal C=\{0\}$. The corresponding unscaled proximal loss is
\[
p(a,\theta)
=
\operatorname{dist}(q(a,\theta),\mathcal C)^2
=
q(a,\theta)^2.
\]
To obtain a low-order Taylor approximation, use the perturbation around the old solution $\delta=\theta-\theta_A^\star$ in the first-order expansion of $q$:
\[
q(a,\theta_A^\star+\delta)
\approx
g^\top\delta,
\]
where
\[
g
=
\nabla_\theta \ell_A(f_{\theta_A^\star}(a)).
\]

Equivalently, writing
\[
z_A=f_{\theta_A^\star}(a)
\qquad
r_i
=
\nabla_z \ell_A(z)\big|_{z=f_{\theta_A^\star}(a)},
\qquad
J_i
=
\nabla_\theta f_{\theta_A^\star}(a),
\]
the chain rule gives
\[
g_i
=
J_i^\top r_i.
\]

Substituting this expansion into the preservation penalty gives
\[
\frac{\lambda}{2N_A}\sum_{i=1}^{N_A} q(a_i,\theta)^2
\;\approx\;
\frac{\lambda}{2N_A}\sum_{i=1}^{N_A} (g_i^\top\delta)^2.
\]
Collecting the gradient outer products yields
\[
\frac{\lambda}{2N_A}\sum_{i=1}^{N_A} (g_i^\top\delta)^2
=
\frac{\lambda}{2}\,
\delta^\top
\left(
\frac{1}{N_A}\sum_{i=1}^{N_A} g_i g_i^\top
\right)
\delta
=
\frac{\lambda}{2}\,
\delta^\top
M_1
\delta.
\]

Therefore the resulting matrix is
\[
M_1
=
\frac{1}{N_A}\sum_{i=1}^{N_A} g_i g_i^\top
=
\frac{1}{N_A}\sum_{i=1}^{N_A} J_i^\top r_i r_i^\top J_i.
\]
This matrix encodes the local parameter directions in which the chosen scalar preservation quantity changes. We call it the \emph{outer-product loss-gradient} (OPG) matrix. The construction is exact for the squared first-order surrogate displayed above, not for the original nonlinear equality constraint. It becomes the observed-label empirical-Fisher algebra only for likelihood losses, as specified next.
