\section*{Checklist}

\begin{enumerate}
  \item For all models and algorithms presented, check if you include:
  \begin{enumerate}
    \item A clear description of the mathematical setting, assumptions,
    algorithm, and/or model. [Yes. The main theoretical development derives the construction and
    Appendix F specifies the executable methods.]
    \item An analysis of the properties and complexity (time, space, sample
    size) of any algorithm. [Yes. The well-fitted, output-geometry,
    notation/boundary, and IEWC sections analyze the construction;
    Appendix F states storage and importance-estimation costs and Appendix C
    reports measured time and peak memory.]
    \item (Optional) Anonymized source code, with specification of all
    dependencies, including external libraries. [Yes. The supplementary
    archive contains both the frozen run source and the reproduction source,
    together with a pinned lockfile.]
  \end{enumerate}

  \item For any theoretical claim, check if you include:
  \begin{enumerate}
    \item Statements of the full set of assumptions of all theoretical results.
    [Yes. The assumptions appear with the corresponding derivations and in
    Appendix A.]
    \item Complete proofs of all theoretical results. [Yes. The results used by
    the method are proved algebraically in the main text and Appendix A.]
    \item Clear explanations of any assumptions. [Yes. The derivations,
    notation/boundary section, and limitations section explain their operational
    consequences.]
  \end{enumerate}

  \item For all figures and tables that present empirical results, check if you
  include:
  \begin{enumerate}
    \item The code, data, and instructions needed to reproduce the main
    experimental results (either in the supplemental material or as a URL).
    [Yes. The supplementary archive contains source, analysis-complete records,
    manifests, checksums, and end-to-end instructions; datasets and checkpoints
    are obtained from their cited sources.]
    \item All the training details (e.g., data splits, hyperparameters, how they
    were chosen). [Yes. Appendix C records the complete frozen protocol,
    selection rule, roles, grids, and training configurations.]
    \item A clear definition of the specific measure or statistics and error
    bars (e.g., with respect to the random seed after running experiments
    multiple times). [Yes. The empirical-evaluation section and Appendix C define the metrics,
    repetitions, paired intervals, randomization tests, and dependence checks.]
    \item A description of the computing infrastructure used. (e.g., type of
    GPUs, internal cluster, or cloud provider). [Yes. Appendix F reports the
    single-workstation CPU/GPU environment and the measured resource fields.]
  \end{enumerate}

  \item If you are using existing assets (e.g., code, data, models) or
  curating/releasing new assets, check if you include:
  \begin{enumerate}
    \item Citations of the creator If your work uses existing assets. [Yes.]
    \item The license information of the assets, if applicable. [Yes. Appendix
    F states the applicable upstream terms and redistribution boundary.]
    \item New assets either in the supplemental material or as a URL, if
    applicable. [Yes. The anonymized supplementary archive contains the new
    protocol, result records, analyses, and source snapshots.]
    \item Information about consent from data providers/curators. [Not
    Applicable. The work uses existing public research benchmarks and does not
    collect new data from people.]
    \item Discussion of sensible content if applicable, e.g., personally
    identifiable information or offensive content. [Not Applicable to the new
    artifacts. No benchmark examples are redistributed, and restricted prompt
    and target fields are removed from archived run records.]
  \end{enumerate}

  \item If you used crowdsourcing or conducted research with human subjects,
  check if you include:
  \begin{enumerate}
    \item The full text of instructions given to participants and screenshots.
    [Not Applicable.]
    \item Descriptions of potential participant risks, with links to
    Institutional Review Board (IRB) approvals if applicable. [Not Applicable.]
    \item The estimated hourly wage paid to participants and the total amount
    spent on participant compensation. [Not Applicable.]
  \end{enumerate}
\end{enumerate}
