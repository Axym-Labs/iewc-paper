\subsection{Outer-Product Loss-Gradient Regularization and EWC}

For the loss functional $s_{a_i}(\theta)=\ell_A(f_\theta(x_i))$, the matrix obtained in the previous section is
\[
M_{\mathrm{OPG}}
=
\frac{1}{N_A}\sum_{i=1}^{N_A}g_i g_i^\top.
\]
It is an outer product of loss gradients. This identity holds for any differentiable loss, without a probabilistic model or a curvature interpretation. We therefore call it an \emph{outer-product-of-loss-gradients} (OPG) matrix.

For a negative-log-likelihood loss,
\[
\ell_i(\theta)=-\log p_\theta(y_i\mid x_i),
\]
we have $g_i=-\nabla_\theta\log p_\theta(y_i\mid x_i)$. The same OPG algebra then coincides with the observed-label score-gradient matrix commonly called the empirical Fisher,
\[
F_{\mathrm{emp}}
=
\frac{1}{N_A}\sum_{i=1}^{N_A}
\nabla_\theta\log p_\theta(y_i\mid x_i)
\nabla_\theta\log p_\theta(y_i\mid x_i)^\top.
\]
Thus OPG-EWC and empirical-Fisher EWC denote the same implementation in an explicit likelihood setting. The CLOC derivation justifies this matrix as the quadratic form of a squared first-order loss-preservation surrogate. It does not turn the matrix into the model Fisher or establish that it approximates the Hessian.

The model Fisher is instead
\[
\begin{aligned}
F_{\mathrm{model}}(\theta)
&=\mathbb E_{x\sim\mathcal D_A}
\mathbb E_{y\sim p_\theta(\cdot\mid x)}
\bigl[
\nabla_\theta\log p_\theta(y\mid x)\\[-2pt]
&\hspace{7em}{}
\nabla_\theta\log p_\theta(y\mid x)^\top
\bigr].
\end{aligned}
\]
It averages over labels sampled from the model, not only the observed label. Under standard regularity conditions this Fisher is connected to expected negative-log-likelihood curvature and natural-gradient geometry \citep{Amari1998,MartensNG,KFAC}. The observed-label empirical Fisher is a different object and can be a poor curvature approximation \citep{KunstnerEF}; Fisher-estimator choice can also materially affect EWC behavior and regularization scale \citep{VanDeVenFisher2025}.

This distinction separates two questions that are often conflated. First, why might the observed-label OPG be a useful continual-learning importance matrix? The local CLOC construction answers: it penalizes first-order changes of old sample losses. Second, is that matrix a faithful estimate of probabilistic Fisher curvature? Not in general. Our experiments therefore include a one-label Monte Carlo model-Fisher baseline, obtained by sampling from the frozen predictive distribution at each supervised output site---one class per image and one token per supervised TRACE answer position---alongside OPG-EWC.

The word ``exact'' below always refers to the algebra of the squared first-order local surrogate. The original hard per-sample constraint, its population counterpart, and the nonlinear loss away from $\theta_A^\star$ remain approximated.
